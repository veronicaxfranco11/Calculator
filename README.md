# Calculator

A simple and responsive calculator built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations and demonstrates the use of different JavaScript function types.

## Features

- Addition, subtraction, multiplication, division, and modulus operations
- Decimal number support
- Clear (C) button
- Delete last character (⌫)
- Error handling for invalid expressions
- Clean Sky Blue & Black user interface
- Responsive design

## JavaScript Concepts Used

- Parameterized Function
- Arrow Function
- Anonymous Function
- DOM Manipulation
- Event Handling
- Basic Expression Evaluation

## Technologies Used

- HTML
- CSS
- JavaScript
